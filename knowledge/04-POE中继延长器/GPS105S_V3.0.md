# GPS105S V3.0 POE中继/延长器

## 产品概述

* 中继器供电功率，取决与上级交换机连接的端口最大功率，超过该功率可能导致中继器重启 * 中继器有端口供电功率优先级功能，所连接的设备总功率过大，会依次关闭4-3-2三个端口供电

## 核心特性

- 二档拔码：WEB+CLOUD（国内出厂默认CLOUD,海外默认WEB）；
- ⽀持微信小程序“云网管”远程管理交换机，支持本地WEB管理；
- 提供4个10/100/1000M自适应POE供电端口，1个上行10/100/1000M自适应受电RJ45端口；
- 支持端口功率优先级供电，超功率会最多关闭3个端口；
- 内置标准交换芯⽚，遵循IEEE802.3以太⽹和IEEE802.3u快速以太⽹协议标准；
- 支持IEEE802.3X全双工流控与Backpressure半双工流控；
- 支持802.1Q VLAN、端口VLAN，适用多种组网业务需求；
- ⽀持帧⻓为1522Byte的数据帧传输；
- 兼容802.3AF/AT供电标准，支持12/36、45/78全八芯受电；
- 支持DHCP Snooping、端口限速、端口镜像、端口管理等管理功能；
- 支持广播/组播风暴抑制；
- 支持端口流量统计；
- 支持MAC地址的自主学习与老化；

## 基本规格

- **端口组成**：4个1000Mbps POE.RJ45端口 + 1个1000Mbps级联RJ45受电端口
- **背板带宽**：10G

## 云网管功能

- **云网管：信息查看**：交换机SN信息、设备型号、固件版本、实时IP、实时端口功率、端口LINK状态、链接双工、上下行速率、VLAN状态；
- **云网管：设备操作**：端口隔离设定、端口重启、端口关闭、端口限速、端口POE开关、端口超远开关、交换机整机重启、整机设定重置、端口双工设置、固件升级、VLAN设置；

## 面板指示灯

- **功能指示灯**（PWR）：交换机电源状态指示，点亮代表设备已启动
- **功能指示灯**（OL）：当设备功率超过20W时，OL指示灯点亮：代表设备过载状态
- **功能指示灯**（CLOUD）：点亮：远程云管理功能开启
- **网口指示灯**（Link/ACT）：点亮：端口link正常；闪烁：数据传输中

## 硬件拨码开关

| 档位 | 模式 | 说明 |
|------|------|------|
| CLOUD | 远程管理模式 | 开启本地WEB管理和远程APP管理功能 |
| WEB | 本地管理模式 | 本地WEB管理模式 |
| RESET | RESET | 开关在 WEB 处，1秒内，拔至CLOUD再拔回WEB ，交换机重启并恢复出厂设置 |
