# GFS226 V1.0 云网管交换机

## 产品概述

提供24个10/100/1000Base-T RJ45端口，2个上行10/100/1000M自适应RJ45端口，2个千兆 SFP端口；。遵循IEEE 802.3以太网、IEEE 802.3u快速以太网、IEEE 802.3ab协议标准；。⽀持微信小程序“云网管”远程管理交换机，支持本地Web管理；。支持端口限速、端口双工设定、端口镜像等端口管理；。

## 核心特性

- 提供24个10/100/1000Base-T RJ45端口，2个上行10/100/1000M自适应RJ45端口，2个千兆 SFP端口；
- 遵循IEEE 802.3以太网、IEEE 802.3u快速以太网、IEEE 802.3ab协议标准；
- ⽀持微信小程序“云网管”远程管理交换机，支持本地Web管理；
- 支持端口限速、端口双工设定、端口镜像等端口管理；
- 支持802.1Q VLAN、MTU-VLAN、Port VLAN，适用多种组网业务需求；
- 支持生成树协议：STP（IEEE802.1d）、RSTP（IEEE802.1w）
- 支持广播、组播风暴抑制；
- 支持DHCP Snooping，限制非法DHCP服务器接入；
- 支持MAC地址的自主学习与老化及手动静态MAC端口绑定；
- 所有端口均支持自动翻转（Auto MDI/MDI-X）功能；
- 支持IEEE802.3X全双工流控与Backpressure半双工流控；
- 云网管：可视化远程管理，现场问题，远程解决；
- 过流过载短路保护，杜绝隐患、受电安全；

## 基本规格

- **端口组成**：24个10/100/1000Mbps .RJ45端口,2个上行10/100/1000M自适应RJ45端口，2个千兆SFP端口
- **背板带宽**：56G
- **MAC地址表**：8K
- **包转发率@64byte（吞吐量）(Mpps)**：41.664Mpps
- **电源规格**：AC输入 100-240V ，24W内置电源
- **网络介质与传输距离**：1000Base-T: 4对超5类（Cat5e)或以上UTP/STP(≤100m) 100Base-TX: 2对5类（Cat5）或以上UTP/STP(≤100m) 10Base-TX: 2对5类（Cat5e）或以上UTP/STP(≤250m)

- **基本功能**：遵循IEEE 802.3 以太网和IEEE802.3u 快速以太网协议标准 兼容符合IEEE 802.3af/at标准的POE供电设备 存储转发 MAC自动学习与老化 IEEE802.3X全双工流控与Backpressure半双工流控

## 云网管功能

- **云网管：信息查看**：交换机SN信息、设备型号、固件版本、实时IP、实时端口功率、端口LINK状态、链接双工、上下行速率、VLAN状态；
- **云网管：设备操作**：端口隔离设定、端口重启、端口关闭、端口限速、端口超远开关、交换机整机重启、整机设定重置、端口双工设置、固件升级、VLAN设置；

## 面板指示灯

- **功能指示灯**（PWR）：交换机电源状态指示，点亮代表设备已启动
- **功能指示灯**（CLOUD）：点亮：远程云管理功能开启
- **网口指示灯**（Link/ACT）：点亮：端口link正常；闪烁：数据传输中

## 硬件拨码开关

| 档位 | 模式 | 说明 |
|------|------|------|
| CLOUD | 远程管理模式 | 开启本地WEB管理和远程APP管理功能 |
| WEB | 本地管理模式 | 本地WEB管理模式 |
| RESET | RESET | 开关在 WEB 处，1秒内，拔至CLOUD再拔回WEB ，交换机重启并恢复出厂设置 |
