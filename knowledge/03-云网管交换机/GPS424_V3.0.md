# GPS424 V3.0 云网管交换机

## 产品概述

遵循IEEE 802.3以太网与IEEE 802.3u快速以太网协议标准；。支持802.3af/at标准协议，智能侦测供电，不烧坏非受电设备；。支持802.1Q VLAN、MTU-VLAN、Port VLAN，适用多种组网业务需求；。二档拔码：WEB+CLOUD（国内出厂默认CLOUD,海外默认WEB）。

## 核心特性

- 遵循IEEE 802.3以太网与IEEE 802.3u快速以太网协议标准；
- 支持802.3af/at标准协议，智能侦测供电，不烧坏非受电设备；
- 支持802.1Q VLAN、MTU-VLAN、Port VLAN，适用多种组网业务需求；
- 二档拔码：WEB+CLOUD（国内出厂默认CLOUD,海外默认WEB）
- ⽀持微信小程序“云网管”远程管理交换机，支持本地Web管理；
- 过流过载短路保护，杜绝隐患、供电安全；
- 支持生成树协议：STP（IEEE802.1d）、RSTP（IEEE802.1w）；
- 支持共模差模防雷；
- 云网管：可视化远程管理，现场问题，远程解决；
- 提供24个1000MPOE RJ45端口，2个1000M RJ45端口及2个1000M SFP端口；
- 所有端口均支持自动翻转（Auto MDI/MDI-X）功能；
- 支持IEEE802.3X全双工流控与Backpressure半双工流控；
- 支持MAC地址的自主学习与老化；
- 全金属外壳，整机满载360W；

## 云网管功能

- **云网管：信息查看**：交换机SN信息、设备型号、固件版本、实时IP、实时端口功率、端口LINK状态、链接双工、上下行速率、VLAN状态；
- **云网管：设备操作**：端口隔离设定、端口重启、端口POE开关、端口限速、端口超远开关、交换机整机重启、整机设定重置、端口双工设置、固件升级、VLAN设置；

## 面板指示灯

- **功能指示灯**（PWR）：交换机电源状态指示，点亮代表设备已启动
- **功能指示灯**（CLOUD）：点亮：远程云管理功能开启
- **网口指示灯**（Link/ACT）：点亮：端口link正常；闪烁：数据传输中

## 硬件拨码开关

| 档位 | 模式 | 说明 |
|------|------|------|
| CLOUD | 远程管理模式 | 开启本地WEB管理和远程APP管理功能 |
| WEB | 本地管理模式 | WEB本地管理模式 |
| RESET | RESET | 开关在 WEB 处，1秒内，拔至CLOUD再拔回WEB ，交换机重启并恢复出厂设置 |
